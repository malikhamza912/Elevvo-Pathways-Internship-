# Front-End Web Development Tasks 🚀

This repository showcases a series of front-end projects I built while practicing modern web development concepts. Each task focuses on different aspects of UI/UX, interactivity, responsiveness, and API integration.  

---

## 📌 Tasks Completed

### 1️⃣ Collapsible Sidebar  
**Description:**  
A responsive sidebar that can expand and collapse when toggled. It includes:  
- A placeholder for a logo  
- A list of navigation links with icons  
- Smooth open/close animations  

**Tech Stack:**  
`HTML` · `CSS` · `JavaScript`  

---

### 2️⃣ Contact Form  
**Description:**  
A responsive contact form that works seamlessly on both mobile and desktop screens. The form includes fields for:  
- Full Name  
- Email Address (with validation)  
- Subject  
- Message  
- Submit Button  

**Features:**  
- Clean, minimal design  
- Input validation (required fields, valid email format)  

**Tech Stack:**  
`HTML` · `CSS` · `JavaScript`  

---

### 3️⃣ One-Page Website for a Task App (TaskFlow)  
**Description:**  
A modern one-page landing site for a fictional productivity app: **TaskFlow**.  

**Sections Included:**  
- **Hero Section:** App name, tagline, and call-to-action  
- **Features:** Three highlighted app features with icons  
- **Testimonials:** Quotes from users  
- **Pricing Plans:** Free, Pro, and Team tiers  
- **Footer:** Contact info and social links  

**Tech Stack:**  
`HTML` · `CSS / Tailwind` · `JavaScript`  

---

### 4️⃣ Multi-Page Dashboard for a Freelance Client  
**Description:**  
An admin dashboard built with React and React Router. Includes:  
- **Overview Page:** Summary cards, recent activity, and charts  
- **Projects Page:** Project list with status and deadlines  
- **Profile Settings Page (Optional):** View/edit profile details  

**Features:**  
- Sidebar and topbar navigation  
- Routing between pages without refresh  
- Charts for earnings and task visualization  

**Tech Stack:**  
`React` · `React Router` · `TailwindCSS` · `Chart.js / Recharts`  

---

### 5️⃣ Real-Time Weather Dashboard (API Integrated)  
**Description:**  
A dashboard that fetches **real-time weather data** from a free API.  

**Features:**  
- Current weather details (temperature, humidity, wind, etc.)  
- Search functionality for cities  
- Option to fetch weather based on **user’s current location** (Geolocation API)  
- Loading and error states for better UX  

**Tech Stack:**  
`React` · `Axios / Fetch API` · `Geolocation API` · `TailwindCSS`  

---
